# 💰 Expense Tracker Web Application

A simple, responsive, and user-friendly **Expense Tracker Web Application** built using HTML, CSS, and JavaScript. It helps users record daily expenses, organize transactions by category, filter expenses, and monitor their spending in one place.

## 📌 Project Overview

The Expense Tracker is a browser-based application designed to make personal expense management easier. Users can add, edit, and delete expenses, view total spending, and organize their transactions using category and date filters.

The application uses **LocalStorage** to save expense data in the browser, so the data remains available after refreshing the page.

## 🎯 Objectives

- Practice JavaScript DOM manipulation and event handling.
- Work with arrays and objects to manage expense data.
- Implement form validation.
- Store data using browser LocalStorage.
- Create dynamic UI updates without reloading the page.
- Implement expense filtering and sorting.

## 💡 How to Use

1. Open the Expense Tracker application.
2. Enter the expense details in the form.
3. Select the appropriate category and date.
4. Add the expense to the list.
5. Edit or delete expenses when needed.
6. Use the available filters to find specific transactions.
7. Review the total spending summary.

## 💾 Data Storage

The application uses the browser's LocalStorage to store expense records.

**Note:** Expense data is stored locally in the browser. It is not automatically synchronized between devices and may be lost if the browser's site data is cleared.
